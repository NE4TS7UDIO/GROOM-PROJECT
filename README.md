# Groom Project — Grid Day

Surprise groomsmen proposal for Neat's wedding: a karting Grand Prix in Antwerp used as the delivery mechanism for a two-stage invite website.

This folder is prepped for the build — nothing here is the live site yet. Start with `CLAUDE.md` for the full context, then:

- `docs/site-spec.md` — the flow, page by page
- `docs/design-brief.md` — colors, type, layout direction
- `docs/content.md` — actual copy to use
- `data/groomsmen.csv` — the list, roles, response tracking
- `assets/references/` — moodboard screenshots (Mansory, Apex Flow, endurance-racing team site)
- `assets/images/` — put sourced photography here
- `assets/logos/` — put wedding marks/monogram here, once available

Open questions that still need answers are listed at the bottom of `CLAUDE.md`.
