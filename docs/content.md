# Content — Grand Jour (site language: French)

Actual copy for the site, in French — all user-facing text ships in French. Replace every `[entre crochets]` placeholder before build.

**On-site brand name: "Grand Jour."** Not a literal translation of "Grid Day" — a deliberate double meaning. On stage 1 it just reads as "the big day" (race day). On stage 2, once it flips, "le grand jour" is the standard French phrase for a wedding day — so the same two words land differently the second time someone reads them. Internal docs (this repo, CLAUDE.md) keep using "Grid Day" as the English working title; the site itself only ever says "Grand Jour."
